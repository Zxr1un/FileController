# Небольшое руководство

## Предисловие

В курсовом проекте реализована возможность работы клиентов приложений контроля версий как по P2P, так и через сервер-ретранслятор.
Подключение к серверу или P2P узлу производится одинаково (выбирается удалённый адресс и в окне управления подключениями (сетевые функции) нажимается кнопка подключиться к серверу).
Выбор узла с сервера осуществляется в окне управления подключениями (сетевые функции). Программно маршрутизация идёт через ID клиентов.

## важно!
при копированнии папок с exe для создания нескольких клиенто не копируйте файл settings.json -- ЭТО ПРОФИЛЬ ПОЛЬЗОВАТЕЛЯ С ЕГО НЕИЗМЕНЯЕМЫМ ID.

## Репозиторий состоит из:
- Двух полных проектов VisualStudio (основное приложение и сервер)
- Отдельно вынесенного кода программ сервера и обычного клиента
- Отдельно exe файла с библиотеками без преднастроек
- Отдельных exe файлов c настройками для тестирования
- Копии пояснительной записки и диаграммы
